# KiraJe v2

Expanded KiraJe MVP with SEO foundations and more tools.

## Run locally
npm install
npm run dev

## Deploy
Push to GitHub and import into Vercel, or redeploy the project from this folder.

## SEO included
- Unique page titles/descriptions
- Canonical URL metadata
- Open Graph metadata
- robots.txt
- XML sitemap
- Internal links
- Indexable explanatory copy
- JSON-LD WebSite structured data
- About/Contact/Privacy/Terms pages

## Important
The payroll, EPF, SOCSO, tax and zakat calculators must be verified against current official rules before being advertised as exact. EPF, for example, uses contribution schedules and rounding rules rather than a simple percentage for many wage ranges. See the official KWSP contribution schedule before production use.

The QR generator currently uses an external QR image service. If you want a fully self-contained version, replace it with a browser-side QR library later.
